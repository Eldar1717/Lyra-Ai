# Свой голос для Лиры · XTTS-v2

Готовая запись подходит: не нужно обучать модель или читать заданный текст. Возьмите **6–12 секунд чистой непрерывной речи** одного человека, без музыки, эха и длительных пауз. Если будете записывать заново, прочтите обычным голосом: «Привет! Сегодня хорошая погода. Я вышла на прогулку, остановилась у реки и послушала, как шумят деревья». Используйте свой голос или голос человека с его разрешения. Не выдавайте результат за подлинную запись.

## Установка один раз

Запускайте команды **из каталога с `server.py`**. Нужен интернет для установки пакетов и скачивания весов (несколько ГБ свободного места). Для быстрого синтеза предпочтительна NVIDIA с поддерживаемым CUDA; без неё используется CPU, паузы могут быть заметными. Сначала проверьте короткую пробу голоса. Базовой Лире XTTS не требуется.

1. Создайте отдельное окружение на **Python 3.11** и активируйте его, чтобы не изменять рабочую установку Лиры:

   **Windows, командная строка (cmd.exe):**
   ```bat
   py -3.11 -m venv .venv
   .venv\Scripts\activate.bat
   ```
   **Linux / macOS:**
   ```sh
   python3.11 -m venv .venv
   . .venv/bin/activate
   ```
2. Установите **согласованную пару** PyTorch и torchaudio. Пример для CPU Windows/Linux:
   ```sh
   python -m pip install --upgrade pip
   python -m pip install torch==2.8.0 torchaudio==2.8.0 --index-url https://download.pytorch.org/whl/cpu
   ```
   На macOS для CPU та же команда без `--index-url ...`. Для NVIDIA используйте [официальную команду PyTorch](https://pytorch.org/get-started/previous-versions/) для вашего драйвера (желательно также 2.8.0). Для версий PyTorch начиная с 2.9 понадобится и совместимый TorchCodec с его системными зависимостями. CUDA не нужна для установки CPU-варианта.
3. Установите движок и загрузите модель:
   ```sh
   python -m pip install coqui-tts==0.28.0 huggingface_hub six
   python setup_xtts.py
   ```
   Установщик покажет ссылку на [лицензию CPML](https://huggingface.co/coqui/XTTS-v2/blob/main/LICENSE.txt). Она ограничивает использование модели и результата некоммерческими целями. Ознакомьтесь с условиями до подтверждения. Скрипт загружает фиксированную ревизию весов с официальной страницы `coqui/XTTS-v2` в `data/xtts-v2/`. Записи голоса при этом не используются.
4. Остановите старый сервер Лиры, если он работает, и запустите `python server.py` **из активированного окружения**. Откройте `http://localhost:8000` в привычном браузере. Браузер и сервер должны находиться на вашем компьютере: загрузка через внешний адрес и Arena-превью отключена. Чат может использовать облачный движок только по вашим прежним настройкам; сам XTTS не использует облачный TTS API.

## Добавить, проверить и использовать голос

1. Откройте **Настройки → Голос → Свой голос · локальный XTTS-v2**. Выберите файл до 16 МБ. WAV — самый переносимый вариант; MP3, OGG/Opus и другие форматы зависят от декодера браузера.
2. Задайте начало отрывка в секундах. Лира берёт следующие 12 секунд (или до конца записи, если осталось не меньше шести). Прослушайте **исходный фрагмент** в плеере, подтвердите согласие и нажмите **Сохранить образец**. Старый образец этого профиля будет заменён. Исходный файл не изменяется.
3. В списке «Голос персонажа» появится **Мой голос · XTTS-v2**. Нажмите **Послушать голос** — теперь вы услышите *новую* фразу, синтезированную по образцу. Нажмите **Сохранить** внизу настроек. Первый синтез дольше: Лира загружает модель в память. Пропорции тембра, акцент и интонация могут отличаться от оригинала.
4. При ошибке Лира покажет сообщение и оставит текстовый ответ; не будет тайком подменять клон системным голосом. Встроенные голоса можно выбрать вручную. Если терминал сообщает о нехватке памяти, попробуйте закрыть другие большие модели или приложения. Проверьте `python -c "import torch, torchaudio; from TTS.tts.models.xtts import Xtts; print(torch.cuda.is_available())"` в том же окружении: `False` означает работу на CPU, а не ошибку. Если загрузка весов прервалась, повторите `python setup_xtts.py`.

## Где находятся личные данные

Только после нажатия «Сохранить образец» браузер передаёт выбранный отрывок как моно WAV на localhost. Один образец на профиль браузера хранится **без шифрования** в `data/voices/`. Веса лежат отдельно. Лира не сохраняет синтезированные ответы или отдельные голосовые эмбеддинги на диск. Кнопка **Удалить образец** удаляет копию Лиры; исходный файл и резервные копии остаются у вас. Удаляйте образец до очистки данных сайта, иначе потеряете ключ профиля. Если ключ уже потерян, при остановленном сервере можно удалить папку `data/voices/` (образцы **всех** профилей). Не публикуйте `data/` и не открывайте сервер в интернет.
