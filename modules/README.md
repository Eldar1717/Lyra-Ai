# Модули Лиры

Каждый модуль — отдельная папка. Ядро Лиры не знает про модули ничего, кроме того, что лежит в `module.json`, поэтому новый режим не требует правок в `app.js`, `index.html` и `server.py`.

```
modules/
  vakhta/                 ← готовый пример: ИИ-вахтёр
    module.json           паспорт модуля
    index.html            страница модуля
    module.js, logic.js, module.css, asr.js
    backend.py            серверная часть: handle(action, data)
```

## Как подключить

1. Положите папку в `modules/`.
2. Перезапустите `python server.py` (список модулей читается при первом обращении; после перезапуска точно свежий).
3. В Лире нажмите **Модули** — модуль появится в списке. Включите его и нажмите **Открыть**.

Состояние переключателей хранится в `data/modules.json`. Выключенный модуль не отдаёт ни страницу, ни API (404 / 403), его кнопка-ярлык пропадает из шапки.

## module.json

```json
{
  "id": "vakhta",
  "name": "ИИ-вахтёр",
  "short": "Вахтёр",
  "version": "1.0.0",
  "description": "Одно-два предложения для карточки в списке модулей.",
  "details": "Необязательные подробности.",
  "entry": "index.html",
  "api": true,
  "icon": "door",
  "tags": ["камера", "доступ"],
  "requires": ["camera"],
  "enabledByDefault": true
}
```

| Поле | Обязательно | Что значит |
|---|---|---|
| `id` | да | Имя папки: латиница, цифры, `_`, `-`, до 32 символов. Должно совпадать с именем папки. |
| `name`, `short` | нет | Название в списке и на кнопке-ярлыке. |
| `version`, `description`, `details`, `tags`, `requires` | нет | Только для карточки в интерфейсе. |
| `entry` | нет | Файл страницы, по умолчанию `index.html`. Без `/` в имени. |
| `api` | нет | `true` — модуль хочет серверный адрес `/api/<id>` (нужен `backend.py`). |
| `icon` | нет | `door` или `module`. |
| `enabledByDefault` | нет | По умолчанию `true`. |

## Адреса

| Адрес | Что отдаёт |
|---|---|
| `/modules/<id>/` | `entry` модуля (статика только из папки модуля) |
| `/modules/<id>/<файл>` | любой файл из папки, кроме `*.py` и скрытых |
| `/api/<id>` | `POST` → `backend.handle(action, data)` |
| `/api/modules` | `GET` список; `POST {"action":"enable"/"disable","id":…}` — переключатель |

Страница модуля живёт по вложенному адресу, поэтому ссылки на общие ресурсы пишите от корня: `/assets/face/face-api.min.js`, `/api/speech`, `/app.js`.

## backend.py

```python
def handle(action, data):
    """action и data приходят из POST /api/<id>; верните словарь — он уйдёт как JSON."""
    if action == 'ping':
        return {'pong': True}
    raise ValueError('Нет такого действия.')  # ValueError → ответ 400
```

`PermissionError` → 403, `OSError` → 503, любое другое исключение → 500 с текстом ошибки. Модуль загружается лениво (при первом запросе) и живёт до перезапуска сервера — кэшируйте состояние в своих переменных.

## Правила и безопасность

- Модуль — это локальный код с полными правами сервера Лиры: он может читать файлы и ходить в сеть. Песочницы нет, поэтому ставьте только свой или проверенный код.
- Пишите данные в `data/` (она в `.gitignore`), не в папку модуля: так настройки и биометрия не попадут в репозиторий.
- Файлы `*.py` наружу не отдаются, выход за пределы папки модуля запрещён (`../` не работает).
- Запросы с чужим `Origin` сервер отклоняет, авторизации пользователей у Лиры нет — не выставляйте сервер в интернет.
- Если модуль работает с камерой, микрофоном или биометрией, покажите в интерфейсе, что именно происходит и как это отключить: у Лиры принято не включать камеру без явного нажатия.
